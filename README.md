# Monsoon Vows — Project 001

A cinematic, photo-led Indian wedding story built with React + Vite + GSAP.

## Concept
- **Category:** Wedding Story / Celebration Experience
- **Visual direction:** Indian monsoon editorial — emerald, ivory, saffron, rain-glass textures
- **Entry experience:** “Open the Monsoon Letter”
- **Story model:** 12 cinematic scenes, not generic landing-page sections
- **Animation language:** GSAP reveal motion, subtle parallax, cinematic image movement
- **Text density:** intentionally low; photography carries the story

## Customization
Edit `src/data.js` to replace:
- couple names
- date and location
- images
- scene titles and short notes
- palette references

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Notes
- Remote wedding photographs are sourced from free Unsplash photo pages and can be replaced from `src/data.js`.
- The experience includes a reduced-motion fallback.
- No forms, secrets, trackers, or customer data collection are included.
